# ⏱️ Stopwatch Web App

A **simple, modern, and responsive Stopwatch application** built using **HTML, CSS, and JavaScript**.  
This project helps beginners understand **timers, intervals, and DOM manipulation**.

---

## 🌐 Live Demo
👉 **[Click here to view live demo](https://durgaprasadcodes.github.io/Stop-Watch/)**

---

## ✨ Features

- ▶️ Start stopwatch  
- ⏸️ Pause / Stop functionality  
- 🔁 Reset timer  
- 🧮 Accurate time calculation (HH:MM:SS:MS)
- 📱 Fully responsive design  
- 🎨 Clean & minimal UI  

---

## 🛠️ Technologies Used

- **HTML5** – Structure  
- **CSS3** – Styling & layout  
- **JavaScript (ES6)** – Timer logic & DOM manipulation
